# Некромант: Оборона Алтаря

Пиксельный survivors-like в браузере: некромант защищает алтарь от волн разъярённых деревенских. Из трупов крестьян поднимаются скелеты, которые дерутся за тебя.

## Что в игре (v7)

- **15 волн** врагов: крестьяне с вилами, псы, стража со щитами (получает половинный урон от болтов), факельщики (сжигают трупы, чтобы ты не поднял из них скелетов)
- **3 босса**: староста Гаврила (волна 5), инквизитор Бонифаций (волна 10), паладин Готфрид (волна 15)
- **Книга мутаций**: после каждой волны — выбор 1 из 3 апгрейдов (урон болтов, скорость каста, лимит и сила скелетов, HP, скорость, лечение алтаря душами)
- **Покадровая анимация** всех персонажей: ходьба, атака, каст (болт вылетает из посоха точно в кадре замаха)
- Души врагов летят в алтарь и лечат его; некромант подпитывается душами (+1 HP)
- WASD / стрелки — движение, магия кастуется автоматически по ближайшей цели, Esc — пауза, M — звук

## Запуск

```bash
npm install
npm run dev      # разработка на http://localhost:3000
npm run build    # сборка в dist/
npm run preview  # проверить сборку
npm run verify   # автотест рендера и управления (нужен Chromium)
```

## Спрайты

Папка `public/sprites/` с PNG-кадрами (~20 МБ) загружается отдельно — через веб-интерфейс GitHub (Add file → Upload files) в эту же ветку, сохраняя структуру `public/sprites/...`. Без спрайтов игра не отрисуется.

## Стек

React + TypeScript + Vite, рендер на Canvas 2D, звук — WebAudio (синтез, без внешних файлов). Целевые платформы: Яндекс Игры, CrazyGames, упаковка в APK под RuStore.
